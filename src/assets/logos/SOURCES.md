# Brand logos

Drop a logo as `<beer-id>.svg` (preferred), `.png` or `.webp` into this folder —
the file name must match the beer id from `src/domain/beers.ts`
(e.g. `augustiner.svg`, `hacker-pschorr.svg`). The app picks it up automatically.

Logos are trademarks. Only add a logo when its use is cleared — ideally a written
OK from the brewery (brand partnership) — and document it below.
